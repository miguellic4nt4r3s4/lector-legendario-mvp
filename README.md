# Lector Legendario MVP

Construye la primera versión funcional del MVP de “LECTOR LEGENDARIO” según la especificación del usuario. Prioriza estrictamente el circuito: estudiante entra/crea héroe → aventura → misión demo → cinco retos originales de selección múltiple LIT → evaluación/retroalimentación → XP y progreso persistentes → recompensa/insignia → docente consulta progreso. Interfaz completa en español, responsive, fantasía/detectivesca no infantil. Usa React/TypeScript, componentes reutilizables y Supabase con esquema relacional, RLS y datos demo (docente, curso 6A, estudiante Alex). No IA, pagos ni publicidad. Implementa las pantallas MVP solicitadas, dejando preparado pero sin sobredimensionar lo futuro. Al finalizar, informa con precisión qué se construyó, tablas de Supabase, lo funcional, lo preparado, configuración manual pendiente e información requerida para continuar.
